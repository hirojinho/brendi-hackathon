## Desktop App (Electron)

This folder contains a self-contained Electron desktop app with two windows:
- **Overlay window** (always-on-top, toggled via global shortcut) with a button to open the full app
- **Main app window** with the embedded React UI (Chat, Review/SRS, Zettelkasten graph, Documents)

The web UI is bundled and embedded directly into the desktop app - no separate web server needed.

### Setup

1. Install dependencies:
```bash
cd desktop
npm install
```

2. Build and run:
```bash
npm run start
```

The build process will:
- Build the React web app with Electron-optimized settings
- Bundle it into `desktop/dist/web/`
- Compile the Electron main process and preload scripts
- Launch the desktop app

### Development

For development with hot reload of the Electron code:
```bash
npm run dev
```

This will:
- Build the web app once (embedded)
- Watch and rebuild Electron main/preload on changes
- Launch Electron

**Note:** The web app is built once at startup. To see web UI changes, rebuild: `npm run build:web && npm run start`

### Global Shortcut

Default: `Cmd/Ctrl+Shift+Space` to toggle the overlay window.

Override by setting `OVERLAY_SHORTCUT` env var:
```bash
OVERLAY_SHORTCUT=CommandOrControl+Shift+A npm start
```

### Files

- `src/main.ts`: Creates overlay and main windows, registers global shortcut, handles IPC `open-main-window`
- `src/preload.ts`: Exposes `window.api.openMainWindow()` to the overlay renderer
- `overlay/index.html`: Minimal UI with an "Open Full App" button
- `dist/web/`: Bundled React app (generated by build)

# Study Assistant Desktop App

macOS desktop overlay application for Study Assistant with embedded backend.

## Features

- **Global Shortcut**: Press `Option+Space` to toggle overlay
- **Chat Interface**: Ask questions with optional RAG support
- **Note Creation**: Save conversations as notes
- **Embedded Backend**: No external server needed - backend runs embedded in Electron
- **Local Databases**: All data stored locally in user's Application Support directory

## Development

### Prerequisites

- Node.js 20+
- npm or pnpm

### Setup

1. Install dependencies for both server and desktop:
```bash
# Install server dependencies
cd ../server
npm install

# Install desktop dependencies
cd ../desktop
npm install
```

2. Start development:
```bash
cd desktop
npm run dev
```

This will:
- Automatically build the server if needed (checks on startup)
- Compile the main process TypeScript (with watch mode)
- Start Vite dev server for the renderer
- Launch Electron app

The `predev` script ensures the server is built before starting Electron.

### Troubleshooting

If you see "Server not built" errors:
```bash
cd ../server
npm run build
```

Then restart the desktop app.

### Configuration

API keys can be configured via the UI (Settings panel - coming soon) or directly via:
- `electron-store` config in `~/Library/Application Support/study-assistant-desktop/config.json`

Set these keys:
- `openaiApiKey`
- `openrouterApiKey`  
- `ollamaBaseUrl`

## Building

Build for production:
```bash
npm run build
```

Package as macOS app:
```bash
npm run package:mac
```

## Project Structure

```
desktop/
├── src/
│   ├── main/           # Electron main process
│   │   ├── main.ts     # Main entry, window management, IPC
│   │   ├── backend.ts  # Backend embedding helper
│   │   └── preload.ts  # Preload script (IPC bridge)
│   └── renderer/       # React renderer process
│       ├── main.tsx
│       ├── App.tsx
│       └── components/
└── dist/               # Compiled output
```

## Notes

- Backend is embedded in the main process
- Databases are stored in `~/Library/Application Support/study-assistant-desktop/`
- Backend listens on `127.0.0.1` (loopback only) for security
